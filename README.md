# Paws & Paths

A full-stack web app that connects pet owners with trusted local dog walkers. Owners create
dog profiles and book walks; walkers accept requests, run walks, and build their reputation
through verified reviews.

WDD 430 — Team Project

## Team

| Name | Role |
|---|---|
| Zureyma Manrique | Team Leader & Full-Stack Developer (working individually) |

## Tech Stack

- Next.js (App Router), React, TypeScript
- Tailwind CSS
- PostgreSQL with Prisma ORM

## Project Structure

- `team-app/` — the Next.js application
- `specs/` — project specification and requirements checklist

## Getting Started

```bash
git clone https://github.com/Zureyma-Manrique/wdd430-team.git
cd wdd430-team/team-app
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
